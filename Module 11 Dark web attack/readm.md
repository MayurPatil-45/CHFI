# CHFI Module 11: Dark Web Activity

## 📌 Overview

This module focuses on understanding **Dark Web activity** from a **digital forensics and cybercrime investigation** perspective, as covered in the **CHFI (Computer Hacking Forensic Investigator)** curriculum. It explains how cybercriminals use the Dark Web, common crimes conducted, investigative challenges, and forensic techniques used to monitor and analyze Dark Web evidence.

---

## 🎯 Learning Objectives

* Understand the structure of the **Surface Web, Deep Web, and Dark Web**
* Learn how criminals operate on the Dark Web
* Identify common Dark Web crimes and marketplaces
* Understand anonymity technologies (Tor, I2P)
* Learn forensic challenges and investigation techniques
* Explore legal and ethical considerations

---

## 🌐 Web Layers Explained

### 1. Surface Web

* Indexed by search engines
* Publicly accessible websites
* Examples: Google, Wikipedia, News sites

### 2. Deep Web

* Not indexed by search engines
* Requires authentication
* Examples: Email accounts, banking portals, private databases

### 3. Dark Web

* Intentionally hidden
* Requires special software (Tor Browser)
* Used for anonymous communication and illegal activities

---

## 🕵️ Dark Web Technologies

### 🔒 Tor (The Onion Router)

* Encrypts traffic in multiple layers
* Masks user identity and location
* Uses `.onion` domains

### 🔒 I2P (Invisible Internet Project)

* Anonymous peer-to-peer communication
* Often used for private messaging and hosting services

---

## 🚨 Common Dark Web Crimes

* Drug trafficking
* Weapons sales
* Hacking services (Malware, DDoS, Exploits)
* Stolen credentials and identity theft
* Credit card and financial fraud
* Human trafficking
* Cryptocurrency laundering

---

## 🛒 Dark Web Marketplaces

* Anonymous online marketplaces
* Use cryptocurrency (Bitcoin, Monero)
* Escrow-based transaction systems
* Reputation-based vendor ratings

**Examples (for educational purposes only):**

* Silk Road (shut down)
* AlphaBay (taken down)
* Hydra Market (seized)

---

## 🧪 Digital Forensics in Dark Web Investigations

### 🔍 Investigation Techniques

* OSINT (Open-Source Intelligence)
* Undercover operations
* Traffic analysis
* Cryptocurrency transaction tracing
* Malware and payload analysis

### 🧾 Evidence Collection

* Screenshots and webpage archiving
* Log analysis
* Wallet address tracking
* Chat and forum analysis

---

## ⚠️ Challenges in Dark Web Forensics

* Strong anonymity and encryption
* Jurisdictional issues
* Use of privacy coins (Monero)
* Rapidly changing marketplaces
* Legal restrictions

---

## ⚖️ Legal & Ethical Considerations

* Follow lawful authorization
* Maintain chain of custody
* Avoid entrapment
* Respect privacy laws
* Ensure evidence admissibility

---

## 🧰 Tools Used in Dark Web Investigations

* Tor Browser (controlled environment)
* Maltego
* OSINT Framework
* Blockchain Explorers
* Wireshark (traffic analysis)
* Autopsy & FTK
