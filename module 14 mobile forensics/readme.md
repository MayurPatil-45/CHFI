Module 14 – Mobile Forensics

This repository contains structured notes, tools, methodologies, and practical references for Module 14: Mobile Forensics, aligned with CHFI / Digital Forensics learning objectives.

**Learning Objectives**

Understand mobile device architecture (Android & iOS)

Learn mobile evidence acquisition techniques

Identify mobile forensic artifacts

Perform logical, physical, and file system extraction

Analyze call logs, SMS, app data, and deleted data

Understand mobile anti-forensics challenges

Generate forensic reports
