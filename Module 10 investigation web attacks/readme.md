CHFI Module 10 – Investigating Web Attacks

This repository documents Module 10: Investigating Web Attacks from the Computer Hacking Forensic Investigator (CHFI) curriculum. It focuses on identifying, analyzing, and documenting evidence related to web-based attacks using forensic methodologies.

📌 Module Overview

Web applications and servers are common attack targets. This module covers forensic techniques to investigate compromised web servers and applications by analyzing logs, identifying attack patterns, and preserving digital evidence.
